OutroKit is a free, open-source .NET CLI and interactive app for creators. Give it a transcript, video, or audio file to generate episode titles, descriptions, YouTube chapters, and SRT captions; it can also transcribe media and help clean up captions. It brings the practical steps from recording to publish-ready assets into one focused tool.
