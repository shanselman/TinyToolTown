rungrep is a CLI tool that lets you quickly find GitHub Actions workflow runs by partial name, right from your terminal. Filter results by branch, status, or workflow, and get direct links to open runs in your browser. It supports JSON output for scripting and integrates with your GitHub authentication seamlessly. Stop scrolling through endless runs—find what you need in seconds!
