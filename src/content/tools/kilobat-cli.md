I built Kilobat CLI to make network troubleshooting less of a scavenger hunt. Run `kilobat why example.com --json` to investigate a failed connection, use the terminal interface, or let an agent use its local stdio MCP server.

The CLI is free and GPL-3.0-only. It requires macOS 14+; `brew install seifip/kilobat/kilobat` builds from source and requires Xcode 16+. The separate menu-bar app is proprietary with free and Pro features. Some CLI data and actions depend on that companion, its licence tier and permissions; the host diagnostic example above runs directly in the CLI. This nomination is for the CLI.
