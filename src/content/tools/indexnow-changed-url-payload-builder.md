IndexNow Changed URL Payload Builder is a free browser-only utility for preparing IndexNow JSON payloads before a site owner notifies participating search engines about added, updated, or deleted URLs. It validates same-host URLs, removes duplicates, holds out malformed entries, and generates a curl command, preflight checklist, Markdown submission note, and CSV export row. It is intentionally small, static, and local-first.
