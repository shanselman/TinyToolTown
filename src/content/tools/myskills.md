I kept installing agent skills and lost track of what I had, what each one did and which I actually used. MySkills runs on your own computer and turns your skills folder into a tidy dashboard. You can read each skill's instructions, sort skills into your own categories, see which ones you use, and send the ones you don't need to the Trash. It needs no account, API key, database or hosting, and an optional backup goes to your own GitHub. To install it, you give Codex a one-line prompt and it sets everything up.
