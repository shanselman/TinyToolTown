Monitor Brightness Control is a sleek WinUI 3 app that lets you adjust brightness independently for every attached monitor using DDC/CI. It features per-monitor sliders, keyboard-first controls, system tray support, and a configurable global hotkey. Native AOT compiled for fast startup, it's a must-have for multi-monitor setups on Windows 10/11.
