Changing monitor input sources without using the monitor's physical buttons.
Add a keybind or make it trigger when a USB is connected/disconnected. I use this to go between my two different computers when switching the USB-HUB. Now I save time by not having to first switch the USB-HUB then also switch both my monitors from DP -> HDMI.
