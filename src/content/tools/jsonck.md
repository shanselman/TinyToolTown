jsonck is a zero-config CLI tool for validating JSON files against JSON Schemas. It supports pipes, globs, remote schemas, and structured JSON output for easy integration with CI, scripts, and LLM tools. Fast and lightweight, jsonck automatically detects schemas or lets you specify them, making validation effortless for any workflow.
