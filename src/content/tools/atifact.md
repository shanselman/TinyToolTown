atifact transforms HAR files, Claude Code logs, and Copilot CLI logs into standardized ATIF v1.6 trajectory JSON. It enables easy debugging, visualization, fine-tuning, and RL pipeline integration for AI agent sessions. With auto-detection of input formats and zero dependencies, atifact streamlines trajectory extraction for developers and AI workflows.
