gitload is a user-friendly CLI tool that lets you quickly download files, folders, or whole repositories from any GitHub URL. It features a colorful progress display, supports ZIP archive creation, and works seamlessly with both public and private repositories. Authentication is flexible, and the tool is optimized for efficiency using GitHub's Trees API. Perfect for developers and AI agents alike!
