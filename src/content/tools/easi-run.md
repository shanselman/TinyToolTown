easi.run gives connected AI agents isolated Chrome sessions on a user's own server, exposed through MCP or REST. A person can watch live, take over for sign-ins, two-factor codes and approvals, then return control to the agent.

It includes encrypted saved profiles, file uploads/downloads, recordings and audio. The connected agent supplies the reasoning. It is free AGPL-3.0-only software; users provide their own Linux x86-64 server, rootful Docker Engine and agent/model resources, with those costs separate.
