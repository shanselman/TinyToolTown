ProxyStat for Windows is a lightweight system tray application that instantly shows whether your system proxy is enabled or disabled. It updates in real time without polling, using native Windows registry notifications. With quick access to proxy settings and a clear icon indicator, it's a convenient tool for anyone managing proxy configurations on Windows 10 or 11.
