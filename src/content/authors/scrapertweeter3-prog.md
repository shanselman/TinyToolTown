I write small command-line utilities that each settle a single question: is this URL up, what is my FIRE number, what does a gadget actually cost per year of its life. Everything is one Python file, standard library only, MIT licensed, built so the output can be piped straight into other scripts. I run a small software studio in Detroit, and every one of these started as a script I kept rewriting for client work until I made it a proper little project.
